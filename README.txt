GYMPOINT - PAGINE PRIVACY E SUPPORTO

FILE
- index.html       Home minimale
- privacy.html     Pagina Privacy, collegata alla policy iubenda
- support.html     Pagina di supporto utente
- styles.css       Stile condiviso

DA MODIFICARE PRIMA DELLA PUBBLICAZIONE
1. Apri privacy.html e sostituisci:
   INSERISCI_LINK_IUBENDA
   con il link pubblico della Privacy Policy che iubenda ti fornisce.

2. Apri support.html e sostituisci tutte le occorrenze di:
   INSERISCI_EMAIL_SUPPORTO
   con la tua email di supporto, per esempio support@gympoint.it.

PUBBLICAZIONE RAPIDA CON GITHUB PAGES
1. Crea un account GitHub, se non ne hai già uno.
2. Crea un nuovo repository, per esempio: gympoint-site
3. Carica nella root del repository i 4 file:
   index.html, privacy.html, support.html, styles.css
4. Nel repository vai in Settings > Pages.
5. In "Build and deployment", scegli "Deploy from a branch".
6. Seleziona branch "main" e cartella "/ (root)", quindi Save.
7. Dopo qualche minuto GitHub ti darà un indirizzo simile a:
   https://TUO-USERNAME.github.io/gympoint-site/
8. Le pagine saranno:
   https://TUO-USERNAME.github.io/gympoint-site/privacy.html
   https://TUO-USERNAME.github.io/gympoint-site/support.html

Per Apple/Google e iubenda puoi usare questi URL pubblici.

DOMINIO PERSONALIZZATO
Se in futuro compri gympoint.it, puoi collegarlo a GitHub Pages o a un altro hosting
e avere URL come:
https://gympoint.it/privacy.html
https://gympoint.it/support.html

NOTA LEGALE
La pagina privacy inclusa qui è una pagina di accesso. Il testo legale vero deve essere
quello generato/configurato in iubenda in base ai servizi effettivamente usati dall'app.
